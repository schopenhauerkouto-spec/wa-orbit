# Déploiement gratuit — SCHOPENHAUER-WA

Prototype: GitHub + Render Free + Supabase Free PostgreSQL + Meta WhatsApp Cloud API + Groq Free tier.

Séquence:
1. Configurer Supabase.
2. Déployer le dépôt sur Render.
3. Ajouter les secrets dans Render Environment.
4. Vérifier /health.
5. Configurer le webhook Meta.
6. Tester un message entrant.
7. Tester STOP.
8. Tester la réponse manuelle.
9. Activer l'IA.
10. Tester le moteur de relation.
11. Activer les follow-ups uniquement pour les contacts explicitement opt-in.

Mode de départ: BOT_AUTO_REPLY_ENABLED=false, pas de prospection proactive, validation humaine.

Le free tier sert au prototype et n'offre pas une disponibilité 24/7 garantie.
